# ANSWER BEAM — U.S. States Edition

▶ **Play: https://mkttr01-afk.github.io/answer-beam-us-play/** · also on itch.io: https://mkttr01-afk.itch.io/answer-beam-us

An educational space shooter: a metal panel shaped like a U.S. state comes flying at your bridge.
Name it (type it, or pick one of four) and shoot it down. The ★ on each panel marks the state capital,
so even the rectangular states can be told apart. Runs in the browser, nothing to install.

- Map data: U.S. Census Bureau cartographic boundary files (2017), public domain; packaged by us-atlas (ISC)
- Music: created with MiniMax-Music3 / Sound effects: Kenney "Sci-Fi Sounds" & "Impact Sounds" (CC0 1.0)
- Libraries: see the bundled THIRD-PARTY-NOTICES.txt

This repository contains only the built game files.
